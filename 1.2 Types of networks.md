## PAN — Personal Area Network

### 1. What is PAN?

PAN stands for **Personal Area Network**. A PAN is a small network that connects personal devices around one person, usually within a short distance.

> **In simple words:** When you connect your mobile phone to your Bluetooth earphones, you are using a PAN.

### 2. How Does PAN Work?

Imagine you have:
- A smartphone
- Bluetooth earphones
- A smartwatch
- A laptop

You can connect these devices using Bluetooth, USB, or other supported wireless technologies.

**Example:**
1. You connect your Bluetooth earphones to your smartphone.
2. Your smartphone sends audio data.
3. Your earphones receive the audio.
4. You can listen to music without using a cable.

This is an example of a PAN.

### 3. Types of PAN

**A. Wireless PAN (WPAN)** — Connects devices without physical cables.

Examples:
- Bluetooth
- NFC (Near Field Communication)
- Zigbee

**B. Wired PAN** — Connects personal devices using physical cables.

Examples:
- USB cable
- USB-C connection
- Other direct device-to-device cable connections

### 4. Characteristics of PAN

- Covers a very small area
- Connects personal devices
- Usually operates within a few metres, depending on the technology
- Can be wired or wireless
- Commonly uses Bluetooth, USB, and NFC
- Generally designed for personal use

### 5. PAN and Cybersecurity

A SOC analyst or security professional should understand possible risks:

- **Bluetooth attacks:** Attackers may try to exploit Bluetooth vulnerabilities
- **Unauthorized connections:** Unknown devices may attempt to connect
- **Data interception:** Poorly secured wireless communication may expose information
- **Malicious devices:** An attacker may use a device to interact with a connected system

Security professionals can investigate suspicious Bluetooth activity and unauthorized device connections.

## LAN — Local Area Network

### 1. What is LAN?

LAN stands for **Local Area Network**. A LAN is a network that connects multiple devices within a small geographical area, such as a home, office, school, or building.

> **In simple words:** When multiple computers, printers, and other devices are connected within an office and can communicate with each other, they form a LAN.

### 2. How Does LAN Work?

Imagine an office has:
- 10 desktop computers
- 2 printers
- 1 file server
- 1 network switch
- 1 router

All computers and devices connect to the network through a switch, usually using Ethernet cables.

**How communication happens:**
1. Computer A wants to send a file to Computer B.
2. Computer A sends data through its network interface.
3. The network switch receives the data.
4. The switch forwards the data towards Computer B.
5. Computer B receives the file.

This communication happens inside the local network.

### 3. Types of LAN

**A. Wired LAN** — Connects devices using physical network cables. The most common technology is Ethernet.

Examples:
- Desktop computers connected using Ethernet cables
- Office computers connected to a network switch
- A server connected to a switch

**Advantages:**
- Stable connection
- Generally faster and more reliable
- Less affected by wireless interference
- Easier to control physical access to the network

**B. Wireless LAN (WLAN)** — Connects devices without Ethernet cables, usually through Wi-Fi access points.

Examples:
- Laptops connected to office Wi-Fi
- Smartphones connected to home Wi-Fi
- Tablets communicating through a wireless access point

> **Important:** WLAN is a type of LAN that uses wireless communication.

### 4. Important LAN Components

| Component | Purpose |
|-----------|---------|
| Switch | Connects devices inside a LAN |
| Router | Connects different networks |
| NIC | Allows a device to connect to a network |
| Ethernet Cable | Carries network data through a wired connection |
| Access Point | Connects wireless devices to a LAN |
| Server | Provides services and resources to other devices |
| Firewall | Controls network traffic based on security rules |

## WLAN — Wireless LAN

### 1. What is WLAN?

WLAN stands for **Wireless Local Area Network**. A WLAN is a type of LAN that connects devices within a limited area using wireless communication instead of physical Ethernet cables.

> **In simple words:** When your laptop, smartphone, and smart TV connect to the same Wi-Fi network, they are using a WLAN.

**Example:** Your home Wi-Fi network is a common example of WLAN.

### 2. How Does WLAN Work?

WLAN commonly uses radio waves to transmit data between wireless devices and a Wireless Access Point (AP).

Imagine you have:
- Wi-Fi router
- Laptop
- Smartphone
- Smart TV

**How communication happens:**
1. Your smartphone searches for available Wi-Fi networks.
2. You select your home Wi-Fi name (SSID).
3. You enter the Wi-Fi password.
4. Your smartphone connects to the wireless access point.
5. The access point sends and receives data wirelessly.
6. Your smartphone can communicate with other network devices and access the internet if the network provides internet connectivity.

### 3. Important WLAN Components

| Component | Meaning |
|-----------|---------|
| Wireless Access Point (AP) | Allows wireless devices to connect to a network |
| Wireless Router | Usually combines routing, Wi-Fi access point, and other network functions |
| Wireless NIC | Allows a device to communicate over Wi-Fi |
| SSID | Name of a Wi-Fi network |
| Antenna | Sends and receives wireless radio signals |
| Wireless Client | A device connected to Wi-Fi, such as a laptop or smartphone |

### What is SSID?

SSID stands for **Service Set Identifier**. It is simply the name of a Wi-Fi network.

For example:
- `Home_WiFi`
- `Office_Network`
- `Guest_WiFi`

When you open Wi-Fi settings on your phone, the network names you see are SSIDs.

## CAN — Campus Area Network

### 1. What is CAN?

CAN stands for **Campus Area Network**. A Campus Area Network connects multiple LANs within a limited geographical area, such as a university campus, hospital campus, or large company campus.

> **In simple words:** Imagine a university has multiple buildings. Each building has its own LAN, and all these LANs are connected together to form one larger campus network. This is called a CAN.

### 2. How Does CAN Work?

Imagine a university has four buildings:
- **Building A** — Administration
- **Building B** — Computer Science Department
- **Building C** — Library
- **Building D** — Student Hostel

Each building has its own LAN. These LANs are connected through a central network infrastructure using switches, routers, and often fiber-optic cables.

**How communication happens:**
1. A computer in Building A sends data.
2. The data travels through its local LAN.
3. Campus network equipment forwards the traffic towards Building C.
4. The destination LAN receives the data.
5. The computer in Building C receives it.

### 3. Important Components of CAN

| Component | Purpose |
|-----------|---------|
| Network Switch | Connects devices within each building's LAN |
| Router | Connects different networks and routes traffic |
| Core Switch | Connects major parts of the campus network |
| Fiber Optic Cable | Connects buildings over high-speed links |
| Wireless Access Point | Provides Wi-Fi connectivity |
| Firewall | Controls and filters network traffic |
| Servers | Provide shared services such as authentication and file storage |

### 4. Advantages of CAN

- Connects multiple LANs across a campus
- Allows communication between different buildings
- Supports centralized network management
- Makes resource sharing easier
- Provides connectivity to shared servers and applications
- Can use high-speed fiber-optic connections

## MAN — Metropolitan Area Network

### 1. What is MAN?

MAN stands for **Metropolitan Area Network**. A MAN is a network that connects multiple LANs or smaller networks across a city or a large metropolitan area.

> **In simple words:** Imagine a company has offices in different parts of Delhi. Each office has its own LAN, and all these offices are connected through a larger network. This network can be called a MAN.

**Example:** A company connects its offices in Delhi, Noida, and Gurugram using a metropolitan network.

### 2. How Does MAN Work?

Imagine a bank has three branches:
- **Branch A** — Delhi
- **Branch B** — Noida
- **Branch C** — Gurugram

Each branch has its own LAN. The bank connects these LANs using a service provider's metropolitan network.

**How communication happens:**
1. A computer in the Delhi branch sends data.
2. Data travels through the branch's local LAN.
3. A router forwards the data towards the metropolitan network.
4. The service provider's network carries the data to the Noida branch.
5. The destination router forwards the data into the Noida LAN.
6. The destination computer receives the data.

### 3. Important Technologies Used in MAN

| Technology | Purpose |
|------------|---------|
| Fiber Optic Cable | Provides high-speed data transmission |
| Metro Ethernet | Connects multiple locations using Ethernet-based services |
| MPLS | Helps service providers forward traffic across large networks |
| DWDM | Allows multiple data signals to travel over a fiber-optic link |
| Microwave Links | Provides wireless connectivity between locations |

## WAN — Wide Area Network

### 1. What is WAN?

WAN stands for **Wide Area Network**. A WAN is a network that connects multiple smaller networks, such as LANs, across large geographical areas, including cities, countries, and continents.

> **In simple words:** Imagine a company has offices in Delhi, Mumbai, London, and New York. Each office has its own LAN, and all these LANs are connected through a WAN.

**Example:** The Internet is the largest and most well-known example of a WAN.

### 2. How Does WAN Work?

Imagine a multinational company has three offices:
- **Office A** — Delhi, India
- **Office B** — London, UK
- **Office C** — New York, USA

Each office has its own LAN. The company connects these offices using WAN technologies and network service providers.

**How communication happens:**
1. A computer in the Delhi office sends data.
2. The data travels through the local LAN.
3. The office router forwards the data towards the WAN.
4. The service provider's network carries the data across geographical locations.
5. The destination router receives the data.
6. The destination LAN delivers the data to the correct computer.

### 3. Important Components of WAN

| Component | Purpose |
|-----------|---------|
| Router | Connects LANs to WAN networks and forwards packets |
| Modem / ONT | Connects customer equipment to certain ISP access technologies |
| ISP | Internet Service Provider that provides network connectivity |
| Leased Line | Dedicated communication link between locations |
| Firewall | Filters and controls network traffic |
| VPN Gateway | Creates secure VPN connections between networks |
| WAN Link | Communication connection between geographically separated locations |

### 4. Technologies Used in WAN

**A. MPLS (Multiprotocol Label Switching)** — A technology used by service providers to forward traffic through a network using labels.

**B. Leased Line** — A dedicated communication connection provided by a service provider. Example: A bank uses a leased line to connect its headquarters with its branches.

**C. VPN (Virtual Private Network)** — Creates an encrypted connection over an existing network, such as the Internet.

**D. SD-WAN (Software-Defined Wide Area Network)** — Uses software-based management to control and optimize connections between different office locations.

### 5. Advantages of WAN

- Connects networks across large geographical areas
- Supports communication between different cities and countries
- Allows centralized access to company resources
- Supports remote working
- Enables communication between global offices
- Provides access to cloud services and applications

## SAN — Storage Area Network

### 1. What is SAN?

SAN stands for **Storage Area Network**. A SAN is a dedicated high-speed network that connects servers to shared storage devices.

> **In simple words:** Imagine a company has 20 servers, but instead of storing all data on individual server hard drives, the company uses a centralized storage system. All servers can access this shared storage through a SAN.

**Example:** A bank uses a SAN to store customer records, transaction data, and database files that multiple servers need to access.

### 2. How Does SAN Work?

Imagine a company has:
- **Server 1** — Database Server
- **Server 2** — Application Server
- **Server 3** — Backup Server
- Central Storage System
- SAN Switches

**How communication happens:**
1. A server needs to read or write data.
2. The server sends a storage request through its storage network interface.
3. The SAN switch forwards the request to the storage system.
4. The storage system processes the request.
5. The requested data is returned to the server.

> **Important:** A SAN commonly provides **block-level storage**. This means servers see storage volumes as disks that they can use to create file systems and store data.

### 3. Important Components of SAN

| Component | Purpose |
|-----------|---------|
| Storage Array | Provides centralized storage capacity |
| SAN Switch | Connects servers and storage systems |
| Host Bus Adapter (HBA) | Connects a server to the storage network |
| Fiber Channel | High-speed technology commonly used in SANs |
| Storage Controller | Manages storage operations and access |
| LUN | Logical Unit Number used to identify a logical storage unit |

### What is HBA?

HBA stands for **Host Bus Adapter**. It is a hardware component that connects a server to a storage network. Think of it as a network interface designed for storage communication.

### What is LUN?

LUN stands for **Logical Unit Number**. It identifies a logical storage unit presented to a server. For example, a storage array may provide a 2 TB logical volume to a database server. That volume can be presented as a LUN.

### 4. Technologies Used in SAN

**A. Fibre Channel (FC)** — A high-speed technology used to transfer storage data between servers and storage systems.

**B. iSCSI (Internet Small Computer Systems Interface)** — Carries SCSI storage commands over TCP/IP networks. It allows servers to access remote block storage using IP networks.

**C. Fibre Channel over Ethernet (FCoE)** — Carries Fibre Channel frames over Ethernet networks.

### 5. SAN vs NAS

| Feature | SAN | NAS |
|---------|-----|-----|
| Full form | Storage Area Network | Network Attached Storage |
| Storage type | Block-level | File-level |
| Connection | Dedicated storage network or IP network | Usually Ethernet/IP network |
| Access | Servers access storage volumes | Users and systems access shared files |
| Common protocols | Fibre Channel, iSCSI | NFS, SMB |
| Common use | Databases, virtualization | File sharing, backups |

> **Easy way to remember:**
> - **SAN** = Provides storage disks to servers
> - **NAS** = Provides shared files and folders over a network

### 6. Real-World Uses of SAN

- **Banking:** Stores large databases and transaction records
- **Hospitals:** Stores medical records and imaging data
- **Data Centres:** Provides shared storage to multiple servers
- **Virtualization:** Provides storage for virtual machines
- **Cloud Infrastructure:** Supports storage systems used by cloud platforms

## VPN — Virtual Private Network

### 1. What is VPN?

VPN stands for **Virtual Private Network**. A VPN creates a secure, encrypted connection between your device and another network over an existing network, such as the Internet.

> **In simple words:** Imagine you are working from home and want to access your company's internal network. A VPN allows you to connect to the company network through an encrypted connection.

**Example:** An employee working from home connects to the company's VPN to access internal files and applications securely.

### 2. Why Do We Need VPN?

Imagine you are using public Wi-Fi at an airport or coffee shop. You want to access company resources, but you don't want your communication exposed to other people on that network. A VPN helps by encrypting traffic between your device and the VPN endpoint.

**Main purposes:**
- Protect data during transmission
- Provide secure remote access
- Connect different company offices
- Protect communication over untrusted networks
- Allow users to access private network resources remotely

> **Important:** A VPN does not automatically make you completely anonymous or protect you from every cyberattack.

### 3. How Does VPN Work?

**Step-by-step process:**
1. Your laptop connects to the Internet.
2. You open the VPN client.
3. You authenticate using your credentials and possibly MFA.
4. Your device establishes an encrypted VPN tunnel to the company's VPN gateway.
5. Your traffic travels through this tunnel.
6. The VPN gateway forwards permitted traffic to internal company resources.
7. You can access authorized applications and servers.

### What is an Encrypted Tunnel?

An encrypted tunnel is a protected communication path through which data travels in encrypted form. Think of it like putting your data inside a locked box before sending it across the Internet. Only the authorized endpoint with the correct cryptographic keys can decrypt that protected communication.

### 4. Types of VPN

**A. Remote Access VPN** — Allows an individual user to connect securely to a private network from a different location.

Example: An employee is working from home in Delhi but needs to access company servers located in Mumbai.

Used for:
- Remote employees
- Work from home
- Secure access to company resources
- Remote IT administration

**B. Site-to-Site VPN** — Connects two or more entire networks through encrypted tunnels.

Example: A company has two offices (Delhi and Mumbai). A Site-to-Site VPN connects their network gateways so that authorized devices in both offices can communicate securely.

Used for:
- Connecting company branches
- Connecting headquarters and remote offices
- Connecting corporate networks
- Secure communication between different locations

### 5. Important VPN Protocols

| Protocol | Description |
|----------|-------------|
| IPsec | Provides security for IP communication; commonly used in Site-to-Site VPNs |
| OpenVPN | Open-source VPN technology that uses TLS for secure connections |
| WireGuard | Modern VPN protocol designed to be simple and efficient |
| IKEv2 | Protocol used to establish and manage IPsec security associations |
| L2TP | Tunneling protocol often paired with IPsec for security |
| PPTP | Older VPN protocol with known security weaknesses |

> **Remember:** Avoid PPTP because it is outdated and insecure. Modern VPN deployments commonly use IPsec, OpenVPN, or WireGuard.

### 6. Important VPN Components

| Component | Purpose |
|-----------|---------|
| VPN Client | Software used by a device to connect to a VPN |
| VPN Server | Handles VPN connections and traffic |
| VPN Gateway | Connects VPN users or networks to private network resources |
| Encryption | Protects data from being read by unauthorized parties |
| Authentication | Verifies the identity of a user or device |
| VPN Tunnel | Protected communication path between VPN endpoints |

## Intranet, Extranet and Internet

These three terms are important in networking because they describe **who can access a network and its resources**.

### 1. Internet

The Internet is a worldwide network that connects millions of private, public, business, and government networks.

> **In simple words:** The Internet allows people around the world to communicate and access information.

**Examples:**
- Google
- YouTube
- Facebook
- Online banking websites
- Email services
- Educational websites

**How does it work?**
1. You open a browser on your laptop.
2. You enter `www.google.com`.
3. Your device sends a request through your ISP.
4. The request reaches Google's servers.
5. Google's server sends a response.
6. Your browser displays the webpage.

**Main characteristics:**
- Publicly accessible services are available to Internet users
- Connects networks worldwide
- Uses TCP/IP-based communication
- Supports websites, email, file sharing, and online services
- No single organization owns or controls the entire Internet

### 2. Intranet

An Intranet is a private network used within an organization. Only authorized employees or members can access its internal resources.

> **In simple words:** Imagine a company has an internal website where employees can check salaries, download documents, view company announcements, and access HR services. This private system is called an Intranet.

**Example:**
A company provides an internal portal: `https://intranet.company.local`

Employees can use it to:
- Check company announcements
- Download internal documents
- Apply for leave
- Access HR information
- View company policies

An external Internet user cannot access these resources without proper authorization and connectivity.

**Main characteristics:**
- Private network
- Used within an organization
- Access is restricted to authorized users
- Can use internal websites and applications
- Usually protected by authentication, firewalls, and access controls

### 3. Extranet

An Extranet is a private network that allows selected external users to access specific resources of an organization's Intranet.

> **In simple words:** Imagine a company wants to share certain documents with its business partners, suppliers, or customers. Instead of giving them access to the entire internal network, the company provides limited access to selected resources. This is called an Extranet.

**Example:**
A company works with three suppliers. The company provides a secure supplier portal where suppliers can:
- Check purchase orders
- Upload invoices
- Track delivery status
- View approved business documents

Suppliers can access only the resources they are permitted to use.

**Main characteristics:**
- Provides controlled access to selected external users
- Used for business communication
- Can connect suppliers, partners, and customers
- Requires authentication and access permissions
- Often uses VPNs, secure web portals, and other security controls

### 4. Real-World Example: One Company

Imagine a company called **ABC Technologies**.

| Network | Who can access it? | Example |
|---------|---------------------|---------|
| Internet | Public users | Company public website |
| Intranet | Authorized employees | Internal HR portal |
| Extranet | Selected external users | Supplier portal |

**Example scenario:**
- A normal visitor opens the company's public website → **Internet**
- An employee logs in to check their salary → **Intranet**
- A supplier logs in to check a purchase order → **Extranet**

### 5. Intranet vs Extranet vs Internet

| Feature | Internet | Intranet | Extranet |
|---------|----------|----------|----------|
| Access | Public services | Authorized internal users | Selected external users |
| Network type | Public/global | Private | Controlled private access |
| Users | Anyone can access public services | Employees or members | Partners, suppliers, customers |
| Security | Depends on individual services | Restricted access | Restricted access |
| Purpose | Global communication | Internal communication | External business collaboration |
| Example | YouTube | Employee portal | Supplier portal |

## Home Network vs Enterprise Network

Both Home Networks and Enterprise Networks connect devices and allow them to communicate. However, they are different in terms of size, complexity, security, management, and infrastructure.

### 1. What is a Home Network?

A Home Network is a network used inside a house or apartment to connect personal devices and share resources.

> **In simple words:** When your smartphone, laptop, smart TV, and printer connect to your home Wi-Fi router, they form a Home Network.

**Example:**
Imagine your home has:
- 2 Smartphones
- 1 Laptop
- 1 Smart TV
- 1 Printer
- 1 Wi-Fi Router

All these devices can connect to the same home network.

**How Does a Home Network Work?**
1. Your ISP provides an Internet connection.
2. The modem or ONT connects to the ISP.
3. Your router provides network connectivity.
4. Your devices connect through Wi-Fi or Ethernet.
5. The router allows devices to communicate and access the Internet according to its configuration.

**Common Components of a Home Network**

| Component | Purpose |
|-----------|---------|
| Router | Connects the home network to other networks, including the Internet |
| Modem/ONT | Connects your home to the ISP's access network |
| Wi-Fi | Provides wireless connectivity |
| Switch | Connects multiple wired devices |
| Smartphone/Laptop | Devices that use the network |
| Printer | Allows users to print over the network |

**Characteristics of Home Network:**
- Small network size
- Usually managed by one person or family
- Uses a home router
- Commonly uses Wi-Fi
- Limited number of connected devices
- Basic security configuration
- Lower management complexity

### 2. What is an Enterprise Network?

An Enterprise Network is a large and complex network used by organizations to connect employees, computers, servers, applications, offices, and other business resources.

> **In simple words:** Imagine a company has 500 employees, multiple departments, several servers, and offices in different locations. All these systems communicate through an Enterprise Network.

**Example:**
A banking company has these departments:
- HR Department
- Finance Department
- IT Department
- Security Department
- Customer Support

Each department may have its own network segment. These segments are connected using enterprise network infrastructure.

**How Does an Enterprise Network Work?**
1. Employees connect their computers through Ethernet or Wi-Fi.
2. Network switches connect devices within departments.
3. VLANs separate different departments or network groups.
4. Routers connect different networks.
5. Firewalls control traffic between network zones.
6. Servers provide services such as authentication, file sharing, and databases.
7. Employees access permitted internal and external resources.

**Common Components of an Enterprise Network**

| Component | Purpose |
|-----------|---------|
| Router | Connects different networks |
| Core Switch | Connects major network segments |
| Access Switch | Connects employee devices |
| Firewall | Filters and controls network traffic |
| IDS/IPS | Detects or prevents suspicious network activity |
| Wireless Access Point | Provides corporate Wi-Fi |
| Servers | Provide business services and applications |
| VPN Gateway | Provides secure remote network access |
| Load Balancer | Distributes traffic across multiple servers |
| SIEM | Collects and analyses security logs and alerts |

## On-Premises vs Cloud Network

Organizations can build and manage their network infrastructure in their own physical locations or use cloud infrastructure provided by companies such as AWS, Microsoft Azure, and Google Cloud.

### 1. What is an On-Premises Network?

An On-Premises Network is a network infrastructure where an organization owns, operates, or directly manages its physical servers, networking devices, and other IT resources at its own location or data centre.

> **In simple words:** A company keeps its own servers, switches, routers, firewalls, and storage systems inside its office or data centre.

**Example:**
Imagine a bank has its own data centre containing:
- Physical servers
- Network switches
- Routers
- Firewalls
- Storage systems
- Backup systems

The bank manages this infrastructure to run its internal applications and databases.

**How Does an On-Premises Network Work?**
1. The company installs physical servers in its data centre.
2. Network switches connect servers and other devices.
3. Routers connect different networks.
4. Firewalls control incoming and outgoing traffic.
5. Employees connect to company resources through the internal network.
6. The company's IT team manages infrastructure, maintenance, and security.

**Common Components**

| Component | Purpose |
|-----------|---------|
| Physical Servers | Run applications and services |
| Router | Connects different networks |
| Switch | Connects devices inside a network |
| Firewall | Filters and controls network traffic |
| Storage System | Stores company data |
| Backup System | Maintains copies of important data |
| Data Centre | Houses IT infrastructure |

**Characteristics of On-Premises Networks:**
- Infrastructure is hosted at the organization's premises or its own data centre
- The organization manages its infrastructure
- Requires physical hardware
- Requires maintenance and upgrades
- Provides direct control over infrastructure
- Requires investment in hardware, electricity, cooling, and physical security

### 2. What is a Cloud Network?

A Cloud Network uses networking infrastructure and services provided through a cloud platform. Instead of maintaining all physical servers and network equipment themselves, organizations use cloud providers such as:
- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)

> **In simple words:** A company can create virtual servers, virtual networks, firewalls, and storage using a cloud provider.

**Example:**
Imagine a company wants to run its website. Instead of purchasing physical servers, it creates virtual machines and a virtual network on AWS. The cloud provider manages the underlying physical infrastructure, while the company configures and manages its cloud resources.

**How Does a Cloud Network Work?**
1. The company creates an account with a cloud provider.
2. It creates a virtual network.
3. It creates subnets inside that virtual network.
4. It launches virtual machines.
5. It configures security groups and network access rules.
6. Users connect to the company's applications over the network.

**Important Cloud Networking Components**

| Component | Purpose |
|-----------|---------|
| Virtual Network | Provides an isolated logical network environment |
| Subnet | Divides a virtual network into smaller network segments |
| Virtual Machine (VM) | Provides a virtual computer for running applications |
| Security Group | Controls permitted traffic to and from supported cloud resources |
| Network ACL | Controls traffic at the subnet level in platforms that support it |
| Cloud Firewall | Filters network traffic |
| Load Balancer | Distributes traffic across multiple servers |
| VPN Gateway | Connects cloud networks to remote or on-premises networks |

### 3. Important Cloud Networking Concepts

**A. VPC (Virtual Private Cloud)** — A logically isolated virtual network inside a cloud platform. For example, AWS provides a service called Amazon VPC. A company can create a VPC with its own IP address range, subnets, routing tables, and network security settings.

**B. Virtual Machine (VM)** — A software-based computer that runs on physical hardware. It can run an operating system such as Windows Server or Linux.

Example: A company creates an Ubuntu virtual machine on AWS to host a website.

**C. Security Group** — Acts as a virtual firewall for supported cloud resources. It controls which network traffic is allowed to reach or leave a resource.

Example: A company configures a security group to allow:
- HTTP — TCP port 80
- HTTPS — TCP port 443
- SSH — TCP port 22 only from an authorized administrator IP address

**D. Subnet** — A smaller network created from a larger IP network. In a cloud environment, subnets help organize resources and control network traffic.

Example:
- **Public Subnet** — Resources that need permitted access from the Internet
- **Private Subnet** — Resources that should not be directly reachable from the public Internet

## Hybrid Network

### What is a Hybrid Network?

A Hybrid Network combines on-premises infrastructure with cloud infrastructure.

> **In simple words:** A company keeps some servers in its own data centre and runs other applications in the cloud.

**Example:**
Imagine a bank:
- Customer database runs in its own data centre
- Website runs on cloud infrastructure
- Both environments communicate through a secure network connection

This is a Hybrid Network.

**Common connection technologies:**
- Site-to-Site VPN
- AWS Direct Connect
- Azure ExpressRoute
- Google Cloud Interconnect
