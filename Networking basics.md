• What is computer Networking?
A computer network is a group of two or more devices connected together to share data, information, and resources.
These devices can communicate with each other using wired or wireless connections.
In simple words:
When two or more computers are connected and can exchange information, they form a computer network.
How does a computer network work?
A computer network works through a few basic steps:
	1. A device creates data.
	2. The device sends the data through a network connection.
	3. Network devices help move the data towards its destination.
	4. The receiving device gets the data.
	5. The receiving device processes the data.
Example: When you send a message to your friend:
	○ Your phone sends the message.
	○ The message travels through a network.
	○ Your friend's phone receives it.

• Why Do We Need Networking?
Imagine you have 10 computers in an office. Every computer needs internet access, file sharing, printer access and communication with other computers.
Without networking, each computer would work independently. Sharing information and resources would become difficult.
Networking solves this problem by connecting devices so they can communicate and share resources.
In simple words:
Networking allows devices to communicate, exchange information, share resources and access services.

• Main reasons why we need networking
Resource Sharing
Networking allows multiple devices to use the same hardware and software resources.
Example:
An office has 20 employees but only one network printer.
All 20 employees can print documents using the same printer through the network.
Benefits:
	○ Saves money.
	○ Reduces hardware requirements.
	○ Makes resource management easier.
File and Data Sharing
Networking allows users to share files and information between computers.
Example:
	• Employee A creates a report.
	• Employee A uploads it to a shared company server.
	• Employee B accesses the same report from another computer.
Benefits:
	○ Easy file sharing.
	○ Centralized storage.
	○ Faster collaboration.
Communication
Networking allows people and systems to communicate with each other.
Examples:
	• Email
	• Instant messaging
	• Video conferencing
	• Voice calls
For example, employees in India can communicate with employees in the USA using Microsoft Teams.

Internet Access
Networking allows devices to connect to the internet and access online services.
Examples:
	○ Browsing websites.
	○ Watching YouTube videos.
	○ Downloading software.
	○ Accessing cloud platforms.
	○ Using online applications.

Centralized Management
Organizations use networking to manage multiple computers and users from a central location.
Imagine a company has 500 computers.
An IT administrator needs to:
	○ Manage user accounts.
	○ Apply security policies.
	○ Install software.
	○ Manage permissions.
	○ Monitor systems.

Remote Access
Networking allows users to access systems and resources from different locations.
Example:
An employee works from home but needs to access a company server.
They can use a company-approved VPN or remote access solution to connect to company resources.
Benefits:
	○ Work from different locations.
	○ Access company resources remotely.
	○ Support remote administration.

Scalability
Networking makes it easier for organizations to expand their IT infrastructure.
Example:
A company initially has 20 computers. After one year, it expands to 100 computers.
The company can expand its network by adding switches, access points, network connections and other required infrastructure.

Reliability and Availability
Organizations use networking technologies to keep services available even when some network components fail.
Example:
A company uses two network connections instead of one.
If the primary connection fails, a backup connection may keep services running.
This is called network redundancy.

What is a Node?
A node is any device or connection point in a computer network that can send, receive, or forward data.
In simple words, any device connected to a network that participates in communication is called a node.
Examples of nodes:
	○ Computer
	○ Laptop
	○ Smartphone
	○ Router
	○ Switch
	○ Network printer
	○ Server
Important: Every host is a node, but not every node is a host. For example, a normal Layer 2 switch is a network node, but it primarily forwards traffic rather than acting as an end host.

What is a Host?
A host is a device connected to a network that acts as a source or destination of communication.
A host commonly has an IP address and can run applications or network services.
Examples include computers, smartphones, servers and IP cameras.

Node vs Host
Node	Host
Any device participating in a network	Usually an endpoint of communication
Can forward network traffic	Can send or receive application data
Example: Switch, router, laptop	Example: Laptop, server, smartphone

What is a Client?
A client is a device or software application that requests services or resources from a server.
In simple words, a client asks for something, and a server provides it.
Real-world example:
When you open YouTube in your web browser:
	1. Your browser acts as a client.
	2. It sends a request to a server.
	3. The server processes the request.
	4. The server sends the requested information back.
	5. Your browser displays the content.
	
What is a Server?
A server is a computer or software application that provides services, data or resources to clients over a network.
In simple words, a server receives requests from clients and provides responses or services.
Common types of servers
Server type	Purpose
Web Server	Hosts websites and web applications
File Server	Stores and shares files
Database Server	Stores and manages data
DNS Server	Resolves domain names
DHCP Server	Assigns IP configuration
Email Server	Sends, receives or stores email
Authentication Server	Verifies user identities

Client vs Server

What is a Network Interface?
A network interface is a hardware or software component that allows a device to connect to a network and communicate with other devices.

Types of network interfaces
Physical interfaces
	• Ethernet adapter
	• Wi-Fi adapter
Virtual interfaces
	○ Loopback interface
	○ VPN tunnel interface
	○ Virtual machine network adapter

Imagine opening a website from your laptop:
	1. Your laptop is a node because it is connected to the network.
	2. Your laptop is a host because it sends and receives data.
	3. Your web browser acts as a client.
	4. The website is provided by a server.
	5. Your Wi-Fi or Ethernet adapter is the network interface.

Components of Data Communication
Whenever two devices communicate over a network, some basic components are required.
There are five main components of data communication:
	1. Sender
	2. Receiver
	3. Message
	4. Transmission Medium
	5. Protocol

What is a Sender?
A sender is a device or system that sends data to another device.
In simple words, the sender is the starting point of communication.
Examples:
	○ Your laptop sending an email.
	○ Your smartphone sending a WhatsApp message.
	○ A computer uploading a file to a server.
	
What is a Receiver?
A receiver is a device or system that receives data from another device.
In simple words, the receiver is the destination of communication.
Examples:
	○ A smartphone receiving a message.
	○ A computer receiving a file.
	○ A server receiving a request from a client.

What is a Message?
A message is the actual information or data that the sender wants to communicate to the receiver.
In simple words, the message is what we want to send.
Examples:
	○ Text messages
	○ Images
	○ Videos
	○ Audio files
	○ Documents
	○ Email content

What is a Transmission Medium?
A transmission medium is the path or channel through which data travels from the sender to the receiver.
In simple words, it is the way data moves between two devices.

Guided Media (Wired)
Data travels through a physical cable.

Unguided Media (Wireless)
Data travels through the air using electromagnetic waves.

Guided vs Unguided Media
Guided Media	Unguided Media
Uses physical cables	Uses wireless signals
Physical connection required	No physical data cable required
Example: Ethernet	Example: Wi-Fi
Example: Fiber optic	Example: Bluetooth

What is a Protocol?
A protocol is a set of rules that controls how devices communicate and exchange data over a network.
In simple words, protocols define how data should be sent, received and understood.
Imagine two people speaking different languages. They may not understand each other.

Common Network Protocols

Network Architecture and Communication Models
This topic explains how a network is designed and how devices communicate with each other.
We will divide it into two parts:
	1. Network Architecture
	2. Network Communication Models

What is Network Architecture?
Network architecture is the design or structure of a computer network. It explains how devices are connected, how they communicate, and how network resources are shared.
For example, imagine a company with 100 computers, 5 servers, printers, and network switches. Network architecture defines how all these devices work together.

There are three common network architectures.

Client-Server Architecture
In this architecture, one or more central servers provide services to client devices.
	• Client: Requests a service or resource.
	• Server: Receives requests and provides services.
Where is it used?
	• Banking systems
	• Company networks
	• Websites
	• Email systems
	• Database applications

Security point: If an attacker compromises a central server, multiple clients or services may be affected.

Peer-to-Peer (P2P) Architecture
In Peer-to-Peer architecture, devices communicate and share resources directly with each other without depending on one central server.
Each device can act as both a client and a server.

Example:
Imagine two computers:
	• Computer A shares a file.
	• Computer B connects directly to Computer A and downloads that file.
Here, Computer A provides the resource, and Computer B uses it.
Where is it used?
	• Direct file sharing
	• Small networks
	• Some multiplayer games
	• Peer-to-peer file-sharing systems
Security point: P2P networks can be harder to manage centrally. An infected device may share malicious files with other devices.

Hybrid Architecture
Hybrid architecture combines client-server and peer-to-peer approaches.

Example:
A company may use:
	• A central server for user authentication and file storage.
	• Direct communication between computers for certain file-sharing activities.
This combines centralized management with direct communication where needed.

Network Communication Models
A communication model describes how data is sent from one device to another or to multiple devices.
There are four important communication methods.

A. Unicast
Unicast means one sender communicates with one receiver.
Example: You open a website, and your computer sends a request to the website's server.
	• Sender: Your computer
	• Receiver: Website server
	• Communication: One-to-one

B. Broadcast
Broadcast means one sender sends data to all devices within a particular broadcast domain.
Example: ARP uses a broadcast request in IPv4 networks to ask which device owns a particular IP address.
	• Sender: One device
	• Receivers: All devices in the broadcast domain
	• Communication: One-to-all
	
C. Multicast
Multicast means one sender sends data to a specific group of receivers.
Example: A company streams a live training session to a group of employees using multicast.
	• Sender: One device
	• Receivers: Selected group
	• Communication: One-to-many (selected group)

D. Anycast
Anycast is a network addressing and routing technique in which the same IP address is assigned to multiple servers located in different geographical locations. When a user sends a request, the network routes it to the nearest or best available server based on routing protocols.
How Anycast Works
	1. Multiple servers in different locations share the same IP address.
	2. A user sends a request to that IP address.
	3. The network routing system determines the best route.
	4. The request reaches the nearest or most suitable server.
Example
Suppose three servers are located in India, the USA, and Germany. All three servers use the same Anycast IP address.
If a user from India sends a request, the network will generally route the request to the Indian server because it offers the best available route.
Uses of Anycast
	• DNS: Improves DNS query response times.
	• CDN: Delivers content from nearby servers.
	• DDoS Protection: Distributes incoming traffic across multiple locations.
	• Network Performance: Helps improve availability and reduce latency.
Advantages
	• Reduces network latency.
	• Improves service availability.
	• Distributes traffic geographically.
	• Provides better performance and reliability.

Connection-Oriented vs Connectionless Communication
In networking, devices communicate using different methods. Two important methods are:
	1. Connection-Oriented Communication
	2. Connectionless Communication
The main difference is whether a connection is established before sending data or not.

1. Connection-Oriented Communication
Connection-oriented communication means two devices establish a connection before exchanging data.
Think of it like a phone call:
	1. You call your friend.
	2. Your friend answers.
	3. Both of you start talking.
	4. You end the call when the conversation is finished.

Example: TCP (Transmission Control Protocol)
TCP establishes a connection using a process called the Three-Way Handshake.
It has three steps:
Step	Packet	Meaning
1	SYN	Client requests a connection.
2	SYN-ACK	Server accepts and responds.
3	ACK	Client confirms the connection.
After these steps, data transmission can begin.
Main Features:
	• Connection is established before data transfer.
	• Reliable data delivery.
	• Uses acknowledgements (ACK).
	• Detects missing data and retransmits it.
	• Maintains data order.
	• Has more communication overhead than connectionless communication.
Common example: TCP is used by many web connections, file transfers, SSH, and email services.

2. Connectionless Communication
Connectionless communication means devices send data without establishing a connection first.
Think of it like sending a postcard:
	1. You write a postcard.
	2. You send it.
	3. It travels through the postal system.
	4. You do not establish a direct conversation before sending it.
Example: UDP (User Datagram Protocol)
UDP sends data without performing a connection handshake.
Main Features:
	• No connection establishment before sending data.
	• No delivery acknowledgement at the UDP protocol level.
	• No guarantee of delivery.
	• No guarantee of packet order.
	• Lower communication overhead.
	• Often suitable for applications that need fast data delivery.
Common examples:
	• DNS queries (commonly UDP)
	• Online gaming
	• Live audio and video streaming
	• Voice and video calls

TCP vs UDP Comparison
Feature	TCP	UDP
Communication type	Connection-oriented	Connectionless
Connection setup	Required	Not required
Reliability	Reliable delivery	No delivery guarantee
Acknowledgement	Yes	No UDP-level ACK
Data ordering	Maintains order	No ordering guarantee
Retransmission	Yes	Not provided by UDP
Overhead	Higher	Lower
Speed/latency	More overhead	Often lower overhead
Example	HTTPS, SSH, FTP	DNS, gaming, VoIP
